Usually, Jutta will send most of the documents for you via Hauspost. In case she is not there and you have to send something, then here is how you do it.

1. First, you need to get a red `Umlaufmappe`. Probably Jutta has some empty ones or you can get an empty one in the Dekanat. It looks like this: ![grafik](uploads/e99954af78d3e48bf0ce4b6204ea2716/grafik.png)
2. Make sure that all of the fields on the front are either empty or striked out.
3. Pick the next free slot and put in the Dezernat or Person in the university you want to send the document to.
4. Put the document in the Umlaufmappe, go to the first floor and put the Umlaufmappe in the post box titled `Hauspost` in the mailroom next to the staircase.
