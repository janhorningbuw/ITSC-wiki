# ITSC Onboarding

A client-side web application for guiding new ITSC members through their onboarding process.

## Features

Onboarding Checklist: Organize onboarding tasks into preparation, first-week, first-month, and general information sections.

Role-specific Onboarding: Provide different onboarding experiences for researchers and student assistants (SHKs).

Task Resources: Provide additional instructions, forms, contact information, email templates, and external links for individual onboarding tasks.

Progress Tracking: Track completed onboarding tasks and display the overall onboarding progress.

Calendar: Visualize onboarding deadlines and important tasks in a monthly calendar.

Campus Information: Provide practical information about the Campus Freudenberg, including the campus map, parking, and building access.

Profile Management: Store the user's name, role, university email address, and start date as part of the onboarding plan.

File I/O: Supports creating, importing, and saving onboarding plans as JSON files.

## Usage

Simply open index.html in a web browser. No server or build step is required.

Click the New plan button to create a new onboarding plan. Enter the user's name, role, university email address, and start date.

Existing onboarding plans can be loaded using Import file. The onboarding plan can be saved as a JSON file and imported again later.

For researchers, the application displays the onboarding checklist, progress information, and calendar. For student assistants (SHKs), a dedicated information view is displayed instead of the checklist and calendar.
